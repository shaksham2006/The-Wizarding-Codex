# The Wizarding Codex — Sorting & Pathfinding Visualizer

The Wizarding Codex is an interactive web project that makes core algorithms easier to understand through animated visualizations.

## Features

### Sorting Chamber
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Random array generation, adjustable array size, and animation speed
- Comparison and swap counters

### Pathfinding Lab
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Dijkstra's algorithm
- Interactive grid with draggable wall drawing
- Animated visited cells and highlighted route
- Clear walls and clear path controls

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.

No build tools or package installation are required.
